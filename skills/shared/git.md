# Git Conventions

## Commit message format
`[agent] short description`

Examples:
- `[be] add POST /api/v1/auth/login`
- `[fe] implement LoginForm component`
- `[be] add validation to user registration`

## Rules
- Never delete files unless explicitly instructed
- Never modify files outside of files_to_touch
- Never touch .env, secrets, or config files
- Commits are automatic — do not include git commands in your output
